# Ciclo 103 - 04/11/2026 21:21-21:29 - P1.103 (v1.2.146)

## Defeito medido

O journal de 04/11 mostrava uma previsao FRESCA a ser descartada por causa de uma
falha de TRANSPORTE do gateway, nao de uma previsao invalida:

```
2026.11.04 21:21:29.101  XAU_AI_PRO (USDJPY,H1)  [AI] PREDICAO VENCIDA | XAUUSD | AGE=6787s > LIMIT=900s
2026.11.04 21:21:44.446  XAU_AI_PRO (USDJPY,H1)  [RESUMO] ... | IA=UNAVAILABLE 0.0% | ...
```

No mesmo instante, a sonda directa ao MESMO endpoint devolvia `available=true`:

```json
{"ok":true,"available":true,"signal":"SELL","confidence":81.0,
 "price":4064.0,"edge":0.0363,"accuracy":0.5361,"model":"XAUUSD 1H"}
```

## Causa raiz

`LoadAIPrediction()` tem duas fontes:

- **FONTE 1** - gateway HTTP (`AIUseGateway`), previsao guardada em memoria no slot
  global `AI_Symbol / AI_Signal / AI_Price`;
- **FONTE 2** - ficheiro local `Data/prediction_<SIMBOLO>.json`.

Quem escreve esse ficheiro e o **pipeline Python**, nao o EA. Medido: o ficheiro
`Data/prediction_XAUUSD.json` estava parado desde ~19:28. Quando a chamada HTTP
falhava por transporte (timeout/WebRequest), o codigo caia para a FONTE 2, lia um
ficheiro com 6787 s, disparava `[AI] PREDICAO VENCIDA` e chamava `ResetAIState()` -
**apagando a previsao fresca que ja estava em memoria**. Resultado:
`IA=UNAVAILABLE 0.0%` com o gateway saudavel.

E o mesmo mecanismo da P1.101, mas na direccao oposta: a P1.101 impedia que a
leitura vencida de OUTRO simbolo apagasse o estado; a P1.103 impede que a propria
leitura de ficheiro substitua uma previsao de gateway ainda valida.

## Correcao aplicada

Em `AI/AIConnector.mqh`, imediatamente ANTES do marcador
`// FONTE 2: ARQUIVO (fallback e modo legado)`:

```mql5
// P1.103 (05/11/2026): se o gateway ja respondeu por ESTE simbolo e a previsao
// em memoria ainda esta dentro de MaxPredictionAgeSec, NAO ler o ficheiro local.
if(AIUseGateway &&
   AI_Symbol == normalized &&
   AI_Price > 0.0 &&
   ultimaConsulta > 0 &&
   MaxPredictionAgeSec > 0 &&
   (long)(TimeCurrent() - ultimaConsulta) <= (long)MaxPredictionAgeSec)
   return true;
```

Propriedades da correccao:

- e **fail-closed**: so devolve `true` quando ja existe previsao real do gateway
  para o simbolo pedido, com preco > 0 e idade dentro do limite;
- nao mexe em `AllowTradeWithoutAI=false` nem em `MinAIConfidence`;
- nao altera a semantica da FONTE 2 para simbolos sem gateway (`AIUseGateway=false`).
