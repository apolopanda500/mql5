# Ciclo 105 - 04/11/2026 21:43-21:50 - P1.102 / P1.105 / P1.106 (v1.2.147)

Tres defeitos de **observabilidade**: o EA negociava igual, mas o journal dizia

## P1.102 - `[RESUMO]` publicava o estado do ULTIMO simbolo visitado

### Defeito medido

No journal de 04/11, a mesma instancia, com 5 segundos de diferenca:

```
21:27:55.044  XAU_AI_PRO (USDJPY,H1)  [AI] GATEWAY | XAUUSD | H1 | 1122 bytes
21:27:55.044  XAU_AI_PRO (USDJPY,H1)  [AI] PYTHON | XAUUSD | SELL | CONF=76.80%
21:28:00.072  XAU_AI_PRO (USDJPY,H1)  [RESUMO] ... | IA=UNAVAILABLE 0.0% | ...
```

Quem le isto conclui "a IA caiu" com a previsao fresca duas linhas acima.

### Causa raiz

`AI_Symbol / AI_Signal / AI_Confidence` sao um **slot unico por instancia**. O
pipeline do grafico master percorre os 11 simbolos da lista dentro da mesma
volta; os 10 simbolos sem modelo publicado passam pelo ramo de recusa
(`ResetAIState()` + `AI_Signal="UNAVAILABLE"`). Quando o `[RESUMO]` saia, o slot
continha o estado do **ultimo** visitado (USDCNH), nao o do par que o grafico
negocia (XAUUSD).

### Correcao

`AI/AIConnector.mqh`:

- cache `g_aiStateSymbol[] / g_aiStateSignal[] / g_aiStateConf[] / g_aiStateWhen[]`
  com `AI_STATE_CACHE_MAX = 32`;
- `AIRecordState(symbol, signal, conf)` chamado no **sucesso** (`return true` do
  parser) e na **recusa** (`available=false`);
- `AIStateForSymbol(symbol, &signal, &conf, &when)` para leitura.

`Monitoring/OperatorBrief.mqh`:

- o `[RESUMO]` le o estado do `_Symbol` do grafico e mostra a idade:
  `IA=SELL 76.8% (ha 12s)`;
- sem entrada na cache, cai para o slot global com `(ultimo <SIMBOLO>)`;
- sem nada, `IA=SEM PRECO`.

A cache e **so de leitura para o resumo**: nao entra em decisao, nao altera
`AI_Signal` e nao toca em nenhum portao. `AllowTradeWithoutAI=false` continua a
bloquear o simbolo cuja propria leitura falhou (o `return false` fica fora da
guarda, como na P1.101).

### Como fechar em runtime

Reattach da v1.2.147 e confirmar numa volta completa de 11 simbolos:

```
[RESUMO] ... | IA=SELL 76.8% (ha Ns) | ...
```

com os simbolos sem modelo a aparecer como `IA=UNAVAILABLE 0.0% (ha Ns)` **na
instancia deles**, e nao a contaminar a do XAUUSD.

O motivo continua no `INDISPONIVEL` com o throttle igual - nao houve duplicacao

## P1.106 - delta de contadores negativo no `[SCANNER] RESUMO`

### Defeito medido

```
18:13:56  [SCANNER] RESUMO | visitas=... | ADX(sem/ok)=-2951/-29135 | SIG(sem/neutro)=...
```

Contadores que ficam negativos depois de um reattach: o modulo de ADX recria os
contadores internos (`Handle`/`CopyBuffer`) enquanto o baseline publicado pelo
scanner sobrevive, logo `actual - baseline` da negativo.

### Correcao

`Core/MarketScanner.mqh`:

```mql5
int MaxInt0(int v) { return(v < 0 ? 0 : v); }
```

aplicado aos quatro deltas (`ADX sem`, `ADX ok`, `SIG sem`, `SIG neutro`). O
baseline e reescrito logo abaixo com o valor actual, logo so a linha daquela
janela era afectada. Um delta negativo nao tem leitura possivel; 0 e a leitura
honesta ("nada medido nesta janela").
